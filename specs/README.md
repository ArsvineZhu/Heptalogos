# Normative Specifications

specs/ is the Normative Contract Plane. It contains exact current
implementation contracts for developers and Coding Agents.

Specs state current invariants, semantic ownership, state models, operations,
lifecycle, failure semantics, cross-boundary requirements, and useful
traceability IDs. A Spec does not authorize implementation; an approved active
Plan does. Future conceptual design belongs in docs/architecture or the
Roadmap. Provider decisions, qualification evidence, Plan sequencing, and
history belong in project/.

See the [Spec index](INDEX.md) for current contracts and the [global INDEX](../INDEX.md)
for adjacent planes.
