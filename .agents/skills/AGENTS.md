# Coding-Agent Skills

A Skill is a recurring, project-specific executor procedure for an already
authorized job. It must provide non-obvious procedural value beyond normal
coding competence, the active Plan, and mature repository tools.

One Skill should cover one coherent implementation job. Its description is
discovery metadata; SKILL.md defines the trigger, information to inspect,
procedure, branches, escalation/stop boundary, and verification scope.
References and scripts exist only when they directly support that job.

A Skill cannot own product Architecture, scope admission, provider selection,
failure-model design, test strategy, or permanent gate design. Those decisions
belong to the active Plan and their canonical knowledge owners. Do not
recursively load another Skill merely because it is mentioned.

The inventory is open-ended. Keep, shrink, or delete Skills from observed
recurring implementation behavior. Do not create a fixed taxonomy, registry,
checklist database, Skill generator, or prose validator.
