# Development roadmap

This directory contains long-lived development sequencing guidance.

- [`development-roadmap.md`](development-roadmap.md) is the canonical Living Roadmap.
- The Roadmap owns sequencing and does not replace Specs, Governance, or the active Plan.
- Future plans should derive their roadmap position, dependency assumptions, risk-retirement needs, and qualification guidance from it.
- Revise the Roadmap when architecture, evidence, or dependency reality changes—not for ordinary file or package refactors.
