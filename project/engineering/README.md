# Engineering knowledge

project/engineering/ contains human and supervisory procedures for maintaining
the repository as part of the Project Control Plane.

| Area          | Use when                                                                                | Entry                                                          |
| ------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Playbooks     | Performing a repeated repository, process, or closure procedure.                        | [Playbook index](playbooks/INDEX.md)                           |
| Gotchas       | Investigating a reproduced failure mode with known evidence and handling.               | [Gotcha index](gotchas/INDEX.md)                               |
| Repository    | Understanding the knowledge system, architecture review, or toolchain responsibilities. | [Repository engineering index](repository/knowledge-system.md) |
| Agent Harness | Maintaining Skill design, authoring, evaluation, and persistent context.                | [Harness entry](agent-harness/README.md)                       |

Plans authorize implementation work. Governance and Dependencies hold standing
project policy and provider decisions. The [global INDEX](../../INDEX.md)
routes the other knowledge planes.
