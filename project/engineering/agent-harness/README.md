# Agent Harness engineering

The Coding-Agent Harness combines persistent repository context with
implementation-time procedural Skills.

- [Design](design.md) explains layers, capability boundaries, typed Authority,
  and maintenance rules.
- [Skill authoring](skill-authoring.md) explains how maintainers create and
  evaluate a coherent Skill.
- [Evaluation](evaluation.md) records behavior-chain scenarios and evidence
  boundaries.
- [Skills](../../../.agents/skills/AGENTS.md) contains the scoped Skill
  authoring context.

Root and scoped AGENTS files persist behavior. Current Specs, Governance,
Dependencies, Plans, and Qualification remain in their canonical planes; this
directory is human-maintainer guidance, not an automatically loaded Skill
bundle.
