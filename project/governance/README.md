# Project Governance

本目录维护 Heptalogos 代码仓库的长期工程治理、产品姿态和兼容政策。

- [Project Charter](project-charter.md)：项目职责与长期产品姿态。
- [Project Constitution](constitution.md)：工程原则、Authority、可靠性和验证约束。
- [PRE_PRODUCTION Evolution](pre-production-evolution.md)：当前兼容、重写和完成政策。
- [Compatibility obligations](compatibility-obligations.json)：唯一机器可读的兼容义务清单。

项目治理规定代码仓库如何演化，不取代 Architecture-Vault 的长期产品目标，也不代替当前 Specs 或 active Plan。
