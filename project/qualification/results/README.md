# Qualification Results

This directory contains executed or explicitly authorized property evidence.
It is not a release-candidate ledger or a second Architecture Authority.

- Provider role decisions live in
  [dependency-status.json](../dependency-status.json).
- Existing Q/C filenames remain as evidence-history identities.
- New records should use semantic names such as
  runtime-cordis-lifecycle.md, durable-execution-process-recovery.md, or
  source-less-windows-package.md.
- A record is created only for an executed property or a concrete pending
  property owned by an active Plan.

Each result should state the property, actual boundary and environment,
evidence command/artifact/reference, and exactly PASS, FAIL, NOT_RUN, or
BLOCKED. Include a tested revision when it is needed to identify the
observed artifact. Do not carry candidate branch, freeze, review, merge, or
revalidation ceremony into a property record.
