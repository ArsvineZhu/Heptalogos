# Project Control Agent Contract

This scope contains project-control artifacts.

- Governance owns standing policy; Dependencies own provider/mechanics
  decisions; Roadmap owns sequencing; the active Plan owns current work
  authorization; Qualification reports observed evidence; Engineering contains
  human or supervisory procedures.
- Keep current and historical state distinct. Historical records preserve
  chronology but do not become current Authority.
- A Plan may prescribe the current change sequence without becoming a
  permanent semantic owner. Link to the relevant Spec or other canonical
  owner.
- Keep machine-readable Authorities at their declared paths and keep evidence
  claims within what was actually executed.
