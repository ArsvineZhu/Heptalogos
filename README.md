# Heptalogos

Heptalogos is a research and prototype repository for an AI-native system
whose Foundation is being developed around explicit ownership, durable
contracts, and executable evidence. The current repository work focuses on
truthful engineering and a reliable Coding-Agent Harness; product runtime
semantics are governed by the current Specs and Roadmap.

Start with the [global repository INDEX](INDEX.md) to route a question:

- [Human Knowledge](docs/README.md) explains product intent, conceptual
  Architecture, and human/developer reference.
- [Normative Contracts](specs/README.md) states exact current implementation
  behavior.
- [Project Control](project/README.md) owns Governance, Dependencies, Roadmap,
  Plans, Qualification, and engineering procedures.
- [Agent Procedures](.agents/skills/AGENTS.md) contains on-demand Coding-Agent
  Skills.

Package ownership and implementation handoffs begin at
[packages/README.md](packages/README.md).
