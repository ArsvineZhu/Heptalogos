# @heptalogos/subject-chat-client

This package is generated from the ProductHost-owned Subject Chat OpenAPI
artifact. Its generated transport surface is intentionally business-rule free;
authentication and Subject/Messaging authority remain server-side concerns.

Regenerate with `pnpm nx run subject-chat-client:generate` and validate with
`pnpm nx run subject-chat-client:generate:check`.
