# Workspace packages

packages/ contains the product and Foundation workspace packages. Each package
README provides the local purpose, semantic ownership, public surface,
relationships, verification, and relevant handoffs.

The [package INDEX](INDEX.md) routes package ownership, public surfaces, and
cross-package handoffs. Exact current behavior belongs in the relevant Specs;
persistent package-workspace behavior belongs in packages/AGENTS.md, and human
procedures belong in project/engineering/.
