# Heptalogos 产品实现范围

长期产品目标和行为设计由 Architecture-Vault 的 Heptalogos 目标设计维护。本页只说明当前代码仓库实现什么。

Heptalogos 是持续 Subject 的 Product Host 与主动行为系统，当前工程重点包括：

- headless Product Host 与 Runtime reconciliation；
- canonical messaging 和 Subject Chat；
- Reaction、BehaviorIntent、Review、DecisionCommit、CommunicationCommit 与 EffectOperation；
- System Authority 与 Management Contract；
- AI Runtime、Capabilities、Extensions 和 Drivers；
- persistence、durable work、Evidence、Execution Lineage、backup/recovery 等可靠运行能力。

长期认知由 Nous Wave 提供。Memory、Self、Social Cognition、Motivation 的领域模型不在本仓库重复维护。

后续主动性工作在 accepted Plan/Spec 后引入 Pursuit，用于连接 Nous Wave 的 Desired Condition 与跨多次 Reaction 的持续行为追求。
